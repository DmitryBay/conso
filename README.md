# Luma Concierge

MVP комплексной платформы для hotel concierge. Реализация идёт по контурам: Platform → Workspace → Guest.

## Что готово

- архитектура ролей и multi-tenancy;
- вход super admin;
- dashboard платформы;
- список, поиск и фильтрация компаний;
- создание/редактирование компании и её владельца;
- адаптивный Bootstrap 5 интерфейс;
- тесты доступа и транзакционного создания аккаунта.
- Workspace владельца и менеджеров;
- конструктор дерева категорий и услуг;
- стартовый многоуровневый шаблон каталога: 6 главных категорий, 15 подкатегорий и 47 услуг, включая ресторан отеля и локальную кухню Бали;
- канбан заявок с назначением и историей статусов;
- database-уведомления и подготовленный Pusher/Echo real-time канал.
- Guest-приложение с отдельным проживанием и персональным PIN для каждого заселения;
- выбор страны гостя на экране входа с тремя основными языками — English, Indonesia и русский — и дополнительными локалями;
- сроки заселения на заданное количество ночей, продление и ручное или автоматическое выселение;
- главное меню гостя из шести крупных плашек на одном экране, без блока популярных услуг;
- четыре мини-маршрута на главном экране: Бали на 1, 2, 3 и 5 дней; система отмечает вариант, подходящий под срок проживания гостя;
- адаптивный каталог и отдельный заказ каждой услуги без корзины;
- история и статус заказов гостя, связанный с канбаном менеджеров.
- счёт номера за проживание с базовой валютой и ориентиром в USD; наличные заказы оплачиваются сразу и учитываются отдельно;
- восемь языков для гостя и менеджера: русский, украинский, индонезийский, английский, арабский, иврит, китайский и корейский; арабский и иврит работают в RTL;
- выбираемые размытые фоны услуг в современной балийской эстетике.

Полное архитектурное описание: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Локальный запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
npm run build
composer run dev
```

Для быстрого локального просмотра можно оставить `DB_CONNECTION=sqlite` и создать пустой файл `database/database.sqlite`. Production-конфигурация рассчитана на MySQL 8.
